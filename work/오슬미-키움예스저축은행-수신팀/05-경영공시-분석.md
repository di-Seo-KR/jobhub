# [실사용] 05. 키움예스저축은행 57기 1분기 경영공시 분석 (감독지표)

> 출처: **키움예스저축은행 제57기 1분기 경영공시**(2026.01.01~03.31, 공시일 2026.05.29). 「상호저축은행업감독규정」 제42조 공시. 04(검토보고서)와 상호보완.

## 한 줄: "건전성이 빠르게 회복 중 — BIS 18.3%, 고정이하여신 1년 새 2,003억→847억"

## 자본적정성 (가장 강력한 면접 카드)
| 지표 | 26.1Q | 25.1Q |
|---|---|---|
| **BIS 자기자본비율** | **18.33%** | 16.50% |
| BIS 기본자본비율 | 13.27% | 11.40% |
| 단순자기자본비율 | 16.92% | 15.33% |
- 규제 최저(약 7~8%)를 크게 상회 → **재무건전성 우량**. 자기자본 2,708억 / 위험가중자산 14,772억.
- 자본금 증자 이력: 2023.05 +400억, **2025.05 +300억**(모회사 키움증권) → 자본 지속 보강.

## 자산건전성 (턴어라운드 핵심 증거)
| 지표 | 26.1Q | 25.1Q |
|---|---|---|
| 총여신 | 11,425억 | 13,056억 |
| **고정이하분류여신** | **847억** | 2,003억 |
| 순고정이하여신 | 414억 | 1,241억 |
| 부실여신(회수의문+추정손실) | 425억 | 517억 |
| 손실위험도가중여신비율 | 12.83% | 19.56% |
- 고정이하여신비율 ≈ **7.4%** (전년 ≈ 15.3%) → 1년 새 절반 이하로 개선.

## 예수금 현황 (수신 직무 직결)
- 형태별: 요구불 1,188억(8.95%) / **거치식(정기예금) 11,801억(88.9%)** / 적립식(적금) 285억(2.15%, 전년 493억 → 감소 지속)
- 예금자별: **개인 7,593억(57.2%)** / 법인·단체 867억(6.53%) / 기타 4,814억(36.3%)
- **영업점 단 2개, 직원 134명, 영업점당 예수금 6,747억** → 점포 최소·**비대면(앱) 중심 수신** 구조 추정
- 정기예금 잔존만기: 1년 이내 6,782억(약 57%) → **재예치·조달비용 관리가 손익에 직결**

## 부동산 익스포저 (균형 시각용)
- 부동산PF 289억 **연체율 0.00%**(안정) / 건설업 304억 연체율 6.38% / **부동산업 1,954억 연체율 13.00%(잔존 리스크)**

## 경영방침 (지원동기·인재상에 직접 인용)
- **혁신경영**(신규영역 개척·전문화) / **소통과 융합**(고객 신뢰·투명경영·지역금융) / **안정적 성장**(리스크관리·체계적 심사)

## 확정/정정
- **대표이사 이동율** (검토보고서 + 경영공시 2건 일치 → 확정. 앞선 웹 '노남열'은 오류)
- 본부: 경영지원본부 / 기업금융본부 / 리테일금융본부(수신은 리테일금융 소관 추정)

## 면접 활용 (강력순)
1. **압박 "어려운 회사인데 왜?" 반격**: "어려웠던 시기를 지나 회복 중이라고 봤습니다. BIS가 18.3%로 규제대비 매우 안정적이고, 고정이하여신이 1년 새 2,003억에서 847억으로 절반 이하가 됐습니다. 지금이 함께 성장하기 좋은 시점이라 판단했습니다."
2. **경영방침 연결(지원동기)**: "'안정적인 성장'과 '소통·신뢰' 경영방침이, 정확성·고객신뢰를 중시하는 제 수신 업무 가치관과 맞닿아 지원했습니다."
3. **수신 직무 기여**: "영업점이 2개로 비대면 중심 수신 구조더라고요. 정기예금 편중(88.9%)과 적금 감소 흐름 속에서, 창구·비대면 양쪽 경험으로 저비용성예금·적금 기반을 넓히는 데 기여하겠습니다."

> 팁: BIS·고정이하 '숫자 1~2개'만 또렷이. 출처는 "회사 분기 경영공시". 부동산업 연체율(13%)은 먼저 꺼내지 말고, 물으면 "잔존 리스크지만 PF는 연체 0%로 관리되고 있다"로 균형있게.
