# [예제] 02. 경험 은행

> ⚠️ 가상 사례. 산출 에이전트: `experience-miner`

## STAR 카드

### 카드 #1 — 캠퍼스 중고거래 앱 사용자 이탈 분석 (졸업 프로젝트)
- **역량 태그**: 분석→액션, SQL, 가설검증, 비즈니스 이해
- **S**: 4인 팀 졸업 프로젝트. 교내 중고거래 앱의 가입 후 1주 내 이탈률이 약 65%로 높았음.
- **T**: 데이터 담당으로서 이탈 원인을 규명하고 개선안을 제시하는 것이 목표.
- **A**: SQL로 사용자 행동 로그를 추출해 가입→첫 거래 퍼널을 단계별로 분석. "검색 후 매물 없음" 경험 비율이 이탈군에서 2.3배 높다는 가설을 세우고 검증. 첫 검색 키워드의 매물 보유율을 지표화해 빈 카테고리를 식별, 푸시 추천 개선안을 제안.
- **R**: 개선안 적용한 학과 베타에서 1주 리텐션이 35%→48%(약 13%p) 상승. 발표에서 "원인 가설→데이터 검증→액션" 흐름으로 우수 평가.
- **활용처**: 직무역량 문항, "분석으로 문제 해결" 질문

### 카드 #2 — 지역 카페 매출 데이터 분석 공모전 (데이터 동아리)
- **역량 태그**: 분석, 시각화·리포팅, 협업
- **S**: 교내 데이터 동아리 5명, 외부 공모전 참가. 소상공인 카페 6개월 POS 데이터 제공.
- **T**: 매출 증대 인사이트 도출 + 발표.
- **A**: 시간대·요일·메뉴별 매출을 분석해 "오후 비수기 + 디저트 결합 구매율 낮음"을 발견. 세트 메뉴/타임할인 시나리오를 시뮬레이션하고 Tableau 대시보드로 시각화. 비전문가 심사위원을 위해 지표를 쉬운 언어로 발표.
- **R**: 참가 32팀 중 **3위 입상**. 제안 세트 메뉴의 예상 객단가 +12% 시뮬레이션 제시.
- **활용처**: 커뮤니케이션·리포팅, 협업 문항, 성취 경험 질문

### 카드 #3 — 편의점 발주·재고 최적화 (아르바이트 1년)
- **역량 태그**: 데이터 기반 개선, 실행력, 책임감
- **S**: 1년간 편의점 근무 중 인기 상품 결품과 비인기 상품 폐기가 반복됨.
- **T**: 발주 정확도를 높여 결품·폐기를 줄이는 것.
- **A**: 6주간 품목별 판매를 엑셀로 기록해 요일·날씨별 패턴을 정리. 결품 잦은 음료/도시락 발주량을 조정하고, 폐기 잦은 품목은 발주 축소를 점장에게 제안.
- **R**: 주요 품목 결품 빈도 체감 감소, 폐기액 월 약 15% 절감(점장 추정). 데이터로 설득해 운영을 바꾼 경험.
- **활용처**: 주도성/실행력 질문, 성격 장점, "사소한 데이터로 개선"
