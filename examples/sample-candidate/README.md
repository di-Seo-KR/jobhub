# 워크드 예제 — 가상 지원자 "김지원"

> ⚠️ 본 폴더는 JobHub 컨설팅팀의 **엔드투엔드 동작을 보여주는 가상 사례**입니다.
> 인물·기업·수치는 모두 허구이며, 실제 기업/인물과 무관합니다.

가상 지원자 **김지원**(통계 전공 신입)이 가상 기업 **한빛커머스**의 **데이터 분석가** 직무에 지원하는 전 과정을, 8개 에이전트가 단계별로 처리한 산출물입니다.

| 단계 | 파일 | 담당 에이전트 |
|---|---|---|
| 인테이크·전략 | `00-profile.md` | intake-strategist |
| 채용공고 분석 | `01-jd-analysis.md` | jd-analyst |
| 경험 정리 | `02-experience-bank.md` | experience-miner |
| 자소서 작성 | `03-cover-letter.md` | resume-writer |
| 자소서 첨삭 | `04-cover-letter-review.md` | resume-reviewer |
| 예상 질문 | `05-interview-questions.md` | interview-designer |
| 답변·모의면접 | `06-interview-answers.md` | interview-coach |

**관찰 포인트** — 산출물 간 일관성:
- JD 핵심역량(SQL·분석→액션) → 경험 은행 카드 → 자소서 문항 → 면접 질문/답변이 **하나의 서사**로 연결됨.
- 자소서의 정량 수치(리텐션 13%p, 객단가 12%)가 면접 꼬리질문으로 검증되고, 답변에서 한계까지 정직하게 다룸.
- 약점(실무 데이터 경험 부재)이 프로필→질문→답변에서 일관되게 '전환 프레임'으로 관리됨.
