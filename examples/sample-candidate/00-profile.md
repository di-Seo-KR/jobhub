# [예제] 00. 지원자 프로필 & 컨설팅 플랜

> ⚠️ 본 예제는 시스템 동작을 보여주기 위한 **가상 사례**입니다. 인물·기업·수치 모두 허구입니다.
> 산출 에이전트: `intake-strategist`

## 1. 기본 정보
- 가명: 김지원 (신입)
- 목표 직무: 데이터 분석가 (이커머스)
- 목표 기업: 한빛커머스(가상) — 국내 종합 이커머스 플랫폼
- 지원 마감일: D-10

## 2. 보유 자산
- 학력/전공: 통계학 전공 (4년제)
- 주요 경험:
  - 졸업 프로젝트: 캠퍼스 중고거래 앱 사용자 이탈 분석
  - 교내 데이터 동아리: 지역 카페 매출 데이터 분석 공모전 입상
  - 편의점 아르바이트(1년): 발주/재고 관리
- 스킬: Python(pandas), SQL, 기초 시각화(Tableau), 통계
- 기존 준비물: 자소서 없음, 이력서 초안만

## 3. 진단
- **강점**: 통계 전공 기반 분석 역량, 실제 데이터로 인사이트→행동을 만든 경험(공모전·아르바이트)
- **약점**: 실무(현업) 경험 부재, 대규모 데이터/프로덕션 경험 없음
- **리스크**: 신입 공통 — "분석을 비즈니스 임팩트로 연결"한 증거가 약할 수 있음
