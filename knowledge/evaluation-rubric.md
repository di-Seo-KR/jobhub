# 지식베이스 · 평가 루브릭

채용 담당자 관점의 채점 기준. `resume-reviewer`·`interview-coach`·`jd-analyst`가 평가에 사용.

## 1. 자기소개서 평가 루브릭 (문항당)

각 항목 1~5점. 합계/30점 → 통과선 권장 **22점 이상**(73%).

| 항목 | 5점(우수) | 1점(미흡) |
|---|---|---|
| **직무적합성** (역량 연결) | JD 핵심역량을 경험으로 정확히 증명 | 직무와 무관한 일반 서술 |
| **구체성·근거** (STAR·정량) | 구체적 행동 + 정량 성과 | 추상적 주장, 근거 없음 |
| **논리·구성** (두괄식) | 두괄식, 메시지 명확, 흐름 자연 | 산만, 결론 불명 |
| **진정성·고유성** | 본인만의 디테일, 솔직 | 클리셰·미사여구·뻔함 |
| **가독성·문장력** | 능동·간결·소제목 활용 | 장황·수동·오탈자 |
| **문항 적합성** | 질문 의도에 정확히 응답 | 동문서답, 분량/글자수 위반 |

**총평 등급**: 27+ 매우우수 / 22~26 통과권 / 17~21 보완필요 / ~16 재작성.

## 2. 자소서 즉시 탈락(레드플래그)

- 글자수 미달/초과, 문항 동문서답
- 다른 회사명 오기재(복붙 흔적)
- 근거 없는 과장·허위 의심
- 오탈자·비문 다수
- 직무 무관, 클리셰로만 채움
- 자소서 내 논리 모순

## 3. 면접 평가 루브릭

각 항목 1~5점.

| 항목 | 평가 내용 |
|---|---|
| **직무역량** | 전문성·문제해결 깊이 |
| **의사소통** | 두괄식·명료·경청 |
| **구체성·일관성** | 근거·수치, 자소서와 일치 |
| **태도·인성** | 솔직·책임감·성장지향 |
| **조직적합(컬처핏)** | 인재상·가치 부합 |
| **상황대응** | 압박·돌발·꼬리질문 대처 |

## 4. 핵심 평가 차원 (기업 공통 관점)

채용은 결국 세 질문에 답하는 것:
1. **직무를 잘할 사람인가?** (직무적합성·역량·전문성)
2. **함께 일할 사람인가?** (조직적합·태도·소통)
3. **성장·지속할 사람인가?** (성장지향·책임감·근속 가능성)

→ 자소서·면접 모든 산출물은 이 3가지에 근거를 제공해야 한다.

## 5. 사용법

- `resume-reviewer`: 문항별 6항목 채점 + 총평 + 레드플래그 점검 → 개선 우선순위.
- `interview-coach`: 모의면접 답변을 면접 루브릭으로 즉시 진단.
- `jd-analyst`: 해당 직무에서 어떤 차원이 가중되는지(예: 영업=소통, 개발=직무역량) 가이드.
