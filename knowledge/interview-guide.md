# 지식베이스 · 면접 가이드

한국 면접 유형·평가·대비. `interview-designer`·`interview-coach` 핵심 참조.

## 1. 면접 유형

| 유형 | 평가 초점 | 대비 핵심 |
|---|---|---|
| **1분 자기소개** | 첫인상·핵심 강점 | 두괄식, 직무 강점 1~2개 + 근거, 30초~1분 |
| **실무진/직무 면접** | 직무 전문성·문제해결 | 경험 심화, 직무 지식, 케이스 |
| **임원/인성 면접** | 가치관·조직적합·태도 | 일관성, 인재상, 솔직함 |
| **PT 면접** | 논리·전달력·문제해결 | 구조화(서론-본론-결론), 시간 관리 |
| **토론(GD) 면접** | 협업·논리·경청 | 주장+근거, 경청·조율, 독주 금지 |
| **압박 면접** | 스트레스 대응·진정성 | 당황 않기, 솔직·논리, 감정 분리 |
| **AI 면접** | 일관성·표현·안정성 | 두괄식, 표정·발화 안정, 시간 관리 |

## 2. 답변 황금 구조

```
1) 결론/핵심 메시지 (두괄식, 한 문장)
2) 근거 경험 (STAR — 간결한 S/T, 충실한 A, 정량 R)
3) 직무/조직 연결 또는 배움 (한 문장 마무리)
```
- 분량: **30초~1분 30초**. 길어지면 핵심이 묻힌다.
- 암기 금지, **구조 기억** 후 자기 말로.

## 3. 빈출 질문 카테고리

- **자기/동기**: 자기소개, 지원동기, 회사/직무 선택 이유, 입사 후 포부.
- **경험/역량**: 가장 큰 성취/실패, 갈등 해결, 리더십, 도전 경험.
- **직무/전문성**: 직무 이해, 전문 지식, 케이스/상황 대응.
- **인성/가치관**: 강약점, 가치관, 스트레스 관리, 동료가 보는 나.
- **자소서 기반 꼬리질문**: 자소서 주장의 근거·수치·역할 검증.
- **약점 정조준**: 공백기, 전공 불일치, 잦은 이직, 짧은 근속.
- **역질문**: "마지막으로 질문 있나요?"

## 4. 자소서 기반 꼬리질문 대비 (핵심)

자소서의 모든 문장은 검증 대상이다.
- "그 30% 개선, 어떻게 측정했나요?"
- "그 결정을 본인이 했다는데, 팀의 반대는 없었나요?"
- "다시 한다면 무엇을 바꾸겠나요?"
→ **수치 근거, 본인 역할, 의사결정 이유, 대안 검토**를 미리 정리.

## 5. 약점 질문 대응 프레임

```
사실 인정 (회피·변명 금지)
  → 원인/맥락 (짧게)
  → 보완 노력과 결과 (구체적)
  → 강점/배움으로 전환
```
예: 공백기 → "○개월 공백은 사실입니다. 그 기간 ○○를 학습/준비했고(증거), 그래서 지금 ○○를 할 수 있습니다."

## 6. 역질문(지원자→면접관) 가이드

- 좋은 역질문: 직무·성장·팀 관련 진지한 질문(예: "이 직무에서 첫 6개월 가장 중요한 성과는 무엇일까요?").
- 피할 질문: 연봉/복지부터(타이밍), 검색하면 나오는 정보, "없습니다".

## 7. 모의면접 운영 (interview-coach)

1. 질문 1개 제시 → 지원자 답변 수령.
2. 피드백: **잘한 점 / 개선점(구조·구체성·길이·일관성) / 모범 예시 / 꼬리질문**.
3. 꼬리질문으로 압박·심화.
4. 반복 후 종합 피드백(반복 약점, 연습 과제).

## 8. 비언어·전달 팁

- 두괄식으로 결론 먼저 → 면접관이 길을 잃지 않음.
- 모르면 솔직히("정확히는 모르지만 이렇게 접근하겠습니다").
- 속도·시선·미소 안정(AI면접·대면 공통).
- 답변 끝을 흐리지 말고 명확히 마무리.
