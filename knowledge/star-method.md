# 지식베이스 · STAR 기법과 경험 구조화

자소서·면접의 모든 경험 서술의 뼈대. `experience-miner`·`resume-writer`·`interview-coach` 공통 기준.

## 1. STAR란

| 요소 | 질문 | 핵심 |
|---|---|---|
| **S**ituation(상황) | 어떤 상황/배경이었나? | 간결한 맥락(규모·제약·기간) |
| **T**ask(과제) | 무엇을 해결/달성해야 했나? | 목표와 나의 역할 |
| **A**ction(행동) | 내가 구체적으로 무엇을 했나? | **본인의 행동·결정**(가장 중요, 분량 최대) |
| **R**esult(결과) | 결과는? 무엇을 배웠나? | **정량 성과** + 의미/배움 |

> 비중 가이드: S 15% / T 15% / **A 50%** / R 20%. 면접관·평가자는 "당신이 한 일"을 본다.

## 2. 좋은 STAR vs 나쁜 STAR

**나쁜 예** (추상적, 팀 성과, 무근거)
> "팀 프로젝트에서 열정적으로 협업하여 좋은 결과를 냈습니다. 많은 것을 배웠습니다."

**좋은 예** (구체·나의 행동·정량)
> "(S) 6명 팀의 졸업 프로젝트에서 배포 지연이 반복됐습니다. (T) 일정 관리 담당으로서 2주 내 안정화가 목표였습니다. (A) 매일 15분 스탠드업을 도입하고, 막힌 작업을 가시화한 칸반보드를 만들었으며, 병목이던 API 연동을 직접 맡아 해결했습니다. (R) 배포 주기를 주 1회에서 주 3회로 늘렸고, 일정 준수율을 60%→95%로 높였습니다. 가시화가 협업 비용을 줄인다는 걸 배웠습니다."

## 3. 정량화 가이드 (수치 캐내기)

수치가 없다고 포기하지 말 것. 다음을 물어 추정·환산한다.
- **규모**: 인원, 예산, 데이터량, 고객 수, 기간.
- **변화율**: 전/후 비교(%, 배수). "20분→14분(30%↓)".
- **순위/비율**: 상위 %, 달성률, 만족도 점수.
- **빈도**: 주/월 단위 처리량, 반복 횟수.
- **간접 지표**: 재구매·재이용, 문의 감소, 오류 감소, 채택/확산.

> 추정 시 "약", "기준" 등으로 표기하고, 면접에서 설명 가능한 근거를 함께 확보한다. **없는 수치를 지어내지 않는다.**

## 4. 역량 태그 (분류 체계)

경험을 아래 역량으로 태깅해 문항/질문에 매핑한다.
- 문제해결 / 분석·데이터 / 기획·전략 / 실행·추진력
- 협업·소통 / 갈등조정·설득 / 리더십·주도성
- 학습·성장 / 도전·끈기 / 책임감·꼼꼼함
- 직무 전문성(스택·도구·도메인 지식)

하나의 경험은 보통 **2~3개 역량**을 동시에 증명한다.

## 5. 경험 발굴 인터뷰 질문 (experience-miner용)

- 가장 어려웠던 문제와 해결 과정은?
- 주도적으로 바꾼 것은? 왜, 어떻게?
- 갈등/이견을 조율한 경험은?
- 실패/실수에서 배운 것은?
- 숫자로 말할 수 있는 성과는?
- 남들과 다르게 접근한 점은?
- 전공/직무 관련 가장 깊이 파고든 경험은?

## 6. 자소서 ↔ 면접 일관성

동일 경험(STAR 카드)을 자소서와 면접에서 **일관되게** 사용한다.
- 자소서: 압축된 서술(글자수 제한).
- 면접: 같은 사실을 구어로 확장 + 꼬리질문 대비(세부 수치·본인 역할·의사결정 근거).
- 모순(수치·역할 불일치)은 즉시 신뢰를 잃는다.
