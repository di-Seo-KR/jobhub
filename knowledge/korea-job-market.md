# 지식베이스 · 한국 취업시장 가이드

JobHub 에이전트가 한국 채용 관행을 이해하기 위한 기준 문서.

## 1. 채용 프로세스 (일반)

```
서류 전형(자소서/이력서)
  → 인적성검사 / AI 역량검사
  → 1차 면접(실무진·직무·PT·토론)
  → 2차 면접(임원·인성)
  → 처우 협의 / 신체검사 / 레퍼런스(일부)
  → 최종 합격
```

- 대기업 공채는 단계가 많고 인적성(GSAT 등)·AI면접 비중이 큼.
- 스타트업/IT는 단계가 압축적이며 직무 과제(코딩테스트·포트폴리오)·컬처핏 면접 비중이 큼.
- 경력직은 보통 서류(경력기술서) → 실무면접 → 임원면접 → 처우.

## 2. 채용 유형

- **공개채용(공채)**: 정기 대규모 채용. 자소서 문항·인적성 표준화.
- **수시채용**: 직무 단위 상시 채용. JD 적합성·직무 경험 중시. (대기업도 수시 전환 추세)
- **블라인드 채용**: 출신학교·성별·나이 등 비공개. **NCS 기반** 직무능력 중심 평가(공기업·공공기관에서 강함).
- **인턴 전환형/채용연계형**: 인턴 후 전환 평가.

## 3. NCS(국가직무능력표준) 개요

- 공공기관·블라인드 채용의 평가 골격. 직무를 "능력단위"로 정의.
- **직업기초능력**(의사소통·문제해결·자원관리·대인관계·정보·기술·조직이해·직업윤리 등 10종)과 **직무수행능력**으로 구성.
- 자소서·면접 문항이 NCS 능력 검증형으로 출제됨(예: "갈등을 해결한 경험" = 대인관계능력).
- 공공기관 지원 시: 직무기술서의 NCS 능력단위를 경험과 매핑하는 것이 핵심.

## 4. 핵심 서류

- **자기소개서**: 문항형. 기업별 4~6문항, 문항당 글자수 제한(보통 500~1,000자). → `cover-letter-guide.md`
- **이력서**: 인적사항·학력·경력·자격·어학·활동. 블라인드는 항목 제한.
- **경력기술서(경력직)**: 프로젝트/성과 중심. 담당 업무·역할·성과(정량)를 구체적으로.
- **포트폴리오(직무별)**: 디자인·기획·개발·마케팅 등.

## 5. 인적성 / AI 역량검사

- **인적성검사**: 적성(언어·수리·추리·공간 등) + 인성검사. 기업별 유형 상이(GSAT, NCS형 등).
- **인성검사**: 일관성 중요. 솔직하되 극단 회피, 직무/인재상과 모순되지 않게.
- **AI 역량검사(예: 인공지능 면접)**: 자기소개·상황질문·게임형 과제·표정/음성 분석. 두괄식·일관성·안정적 표정/발화가 유리.

## 6. 면접 유형 (요약)

상세는 `interview-guide.md` 참조.
- 실무진(직무) / 임원(인성) / PT / 토론(GD) / 압박 / AI / 1분 자기소개.

## 7. 채용 일정 감각

- 상반기(3~5월), 하반기(9~11월) 공채 집중. 수시는 연중.
- 서류 마감 → 발표까지 2~4주, 전체 전형 1.5~3개월 소요가 흔함.
- **마감 역산**: 마감 D-day 기준으로 자소서 작성·첨삭 반복(최소 2~3회전) 시간을 확보하도록 컨설팅 일정을 짠다.

## 8. 직무기술서(JD) 읽는 법

- **담당업무(R&R)**: 실제 하는 일 → 증명할 경험 유형 도출.
- **자격요건(필수)**: 미충족 시 탈락 가능 → 반드시 충족/근접 증명.
- **우대사항**: 차별화 포인트 → 있으면 강조.
- **인재상/핵심가치**: 자소서·면접 키워드. 컬처핏 평가 기준.

## 9. 한국시장에서 통하는 것 / 안 통하는 것

| 통한다 | 안 통한다 |
|---|---|
| 직무 연관 경험 + 정량 성과 | 추상적 열정·각오 |
| 두괄식·소제목 | 장황한 성장사 나열 |
| 기업/직무 이해(구체적 근거) | "귀사의 비전에 공감" 같은 공허한 문구 |
| 일관된 직무 스토리(자소서-면접) | 자소서와 면접 답변 불일치 |
| 솔직한 약점 + 보완 노력 | 약점 회피·완벽한 척 |

## 10. 윤리·리스크 주의

- **표절/AI 검출**: 동일 문장 재사용·정형화된 AI 문체는 위험. 개인 고유 경험·디테일로 차별화.
- **허위 기재**: 경력·자격 허위는 합격 취소·법적 문제. JobHub는 **사실 기반 표현**만 돕는다.
- **블라인드 위반**: 블라인드 전형에서 출신학교·집안 등 노출 금지.
