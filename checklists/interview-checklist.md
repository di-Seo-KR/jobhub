# 체크리스트 · 면접 대비

> `interview-designer`·`interview-coach` 기준 / 지원자 최종 점검.

## 1. 준비 범위
- [ ] 1분 자기소개 (구조 기억, 30초~1분)
- [ ] 지원동기·입사 후 포부
- [ ] 직무 전문성 심화 질문
- [ ] 성취/실패/갈등/리더십 경험 각 1개 이상
- [ ] 자소서 기반 꼬리질문(주장별 근거·수치·역할)
- [ ] 약점 정조준 질문(공백기·전공·근속 등)
- [ ] 역질문 2개

## 2. 답변 품질
- [ ] 두괄식(결론 먼저)인가
- [ ] STAR로 근거가 구체적인가
- [ ] 1분 내외 분량인가(장황 X)
- [ ] 자소서·경험 은행과 사실이 일치하는가
- [ ] 암기가 아닌 구조 기반으로 말하는가

## 3. 약점 대응
- [ ] "사실 인정 → 보완 노력 → 강점 전환" 프레임 준비
- [ ] 회피·변명 없이 솔직하게

## 4. 유형별
- [ ] PT: 서론-본론-결론 구조 + 시간 관리
- [ ] 토론: 주장+근거, 경청·조율(독주 금지)
- [ ] 압박: 감정 분리, 논리 유지
- [ ] AI: 두괄식, 표정·발화 안정, 시간 관리

## 5. 당일
- [ ] 기업 최신 이슈 1~2개 숙지
- [ ] 직무·인재상 키워드 재확인
- [ ] 모의면접 피드백의 반복 약점 교정 확인
