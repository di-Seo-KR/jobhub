# 체크리스트 · 자기소개서 품질

> `resume-writer` 자가점검 / `resume-reviewer` 검수 기준. 모두 ✅ 되어야 제출 권장.

## 1. 구조
- [ ] 두괄식인가 (첫 문장/소제목에 핵심 메시지)
- [ ] 소제목이 본문을 정확히 요약하는가
- [ ] 한 문단 = 한 메시지로 정리됐는가

## 2. 근거·구체성
- [ ] 모든 주장에 경험(STAR) 근거가 있는가
- [ ] 결과가 정량/구체적으로 표현됐는가
- [ ] "팀이 아닌 나의 행동"이 분명한가
- [ ] [확인 필요] 표시한 미검증 사실을 지원자와 확인했는가

## 3. 직무 적합
- [ ] JD 핵심역량/키워드가 녹아 있는가
- [ ] 결국 "이 직무를 잘할 사람"으로 수렴하는가
- [ ] 문항 의도에 정확히 답했는가

## 4. 진정성·고유성
- [ ] 클리셰("어릴 적부터", "열정", "최선을 다하겠습니다") 없는가
- [ ] 근거 없는 과장 수식어 없는가
- [ ] 본인만의 디테일(고유명사·수치·장면)이 있는가
- [ ] 면접에서 본인이 말로 설명 가능한 내용인가

## 5. 형식
- [ ] 글자수 제한 충족(90~100% 활용, 공백 기준 확인)
- [ ] 능동태 위주, 비문/오탈자 없음
- [ ] 다른 회사명·복붙 흔적 없음

## 6. 윤리
- [ ] 허위·과장 경력 없음(사실 기반)
- [ ] 블라인드 위반 정보(출신학교 등) 없음(해당 전형 시)
- [ ] AI 정형 문체 최소화, 본인 소화 완료
