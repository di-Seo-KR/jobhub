# JobHub — 취업 컨설팅 에이전트팀

> 한국 취업시장에 최적화된 **AI 컨설팅 팀**입니다. 자기소개서 작성·첨삭, 면접 질문/답변 설계, 기업·직무 분석, 취업 전략 수립까지 한 팀이 끝까지 지원합니다.

Claude Code의 서브에이전트(subagent) 기능을 활용해, 각 분야를 전담하는 **8명의 컨설턴트 에이전트**가 협업합니다. 사용자는 자연어로 요청만 하면, 총괄 컨설턴트(메인 Claude)가 적절한 팀원에게 일을 배분하고 결과를 종합합니다.

---

## 무엇을 해주나요?

| 영역 | 산출물 |
|---|---|
| 📋 **취업 전략** | 지원자 진단, 목표 직무/기업 선정, 컨설팅 로드맵 |
| 🔍 **기업·직무 분석** | 채용공고(JD) 해부, 인재상·핵심역량·키워드, NCS 매핑 |
| 🧩 **경험 정리** | 보유 경험을 STAR·역량 단위로 구조화한 "경험 은행" |
| ✍️ **자기소개서** | 문항별 두괄식 초안 (직무역량·지원동기·성장·포부 등) |
| 🔴 **자소서 첨삭** | 클리셰 제거, 근거·정량화 강화, 글자수·가독성·평가 루브릭 |
| ❓ **면접 질문** | 인성·직무·상황·압박·PT·토론 예상 질문 풀 |
| 🎤 **면접 답변·모의면접** | STAR 기반 답변 설계, 모의면접 피드백 |
| 🌐 **시장·기업 리서치** | 산업 동향, 채용 프로세스, 기업 정보 (웹 검색) |

## 컨설팅 팀 구성

| 에이전트 | 역할 | 한 줄 설명 |
|---|---|---|
| `intake-strategist` | 인테이크·전략 총괄 | 지원자를 진단하고 전체 컨설팅 플랜을 설계 |
| `jd-analyst` | 채용공고·직무 분석가 | JD/기업을 해부해 핵심역량·키워드를 도출 |
| `experience-miner` | 경험·경력 정리 전문가 | 흩어진 경험을 STAR 소재로 발굴·구조화 |
| `resume-writer` | 자기소개서 작성 전문가 | 문항별 자소서 초안을 두괄식·근거 중심으로 작성 |
| `resume-reviewer` | 자소서 첨삭·평가관 | 냉정한 첨삭과 평가 루브릭으로 완성도 점검 |
| `interview-designer` | 면접 질문 설계자 | JD·자소서 기반 예상 질문 풀 생성 |
| `interview-coach` | 면접 답변 코치 | STAR 답변 설계 + 모의면접 진행·피드백 |
| `market-researcher` | 시장·기업 리서처 | 산업/기업/채용 동향을 웹에서 조사 |

> 팀 운영 규칙과 협업 흐름은 [`CLAUDE.md`](./CLAUDE.md)에 정의되어 있습니다.

## 빠르게 시작하기

이 저장소를 연 Claude Code 세션에서 자연어로 요청하세요.

```text
"삼성전자 DX 부문 SW 개발 직무에 지원할 건데, 자소서랑 면접까지 풀세트로 준비해줘."
```

```text
"내 경험 정리부터 도와줘. 어떤 걸 알려주면 될까?"
```

```text
"이 자소서 문항 첨삭해줘: [문항/내용 붙여넣기]"
```

총괄 컨설턴트가 필요한 정보를 질문하고, 단계별로 팀원을 호출해 산출물을 만들어 드립니다.

### 추천 워크플로우 (풀 패키지)

```
1) 인테이크/전략   → intake-strategist
2) 채용공고 분석   → jd-analyst (+ market-researcher)
3) 경험 정리       → experience-miner
4) 자소서 작성     → resume-writer
5) 자소서 첨삭     → resume-reviewer  (3~5 반복)
6) 예상 질문 설계  → interview-designer
7) 답변·모의면접   → interview-coach
8) 최종 종합 리포트 → intake-strategist
```

## 설계 철학

1. **근거주의** — 모든 문장은 경험·수치·사실에 근거합니다. 미사여구·클리셰를 배격합니다.
2. **직무중심** — 채용공고의 핵심역량과 지원자 경험을 1:1로 연결합니다.
3. **한국시장 정합성** — 문항형 자소서, 글자수, 블라인드/NCS, 인적성·AI면접 등 국내 관행을 반영합니다.
4. **반복 개선** — 작성 → 첨삭 → 재작성 루프로 완성도를 끌어올립니다.
5. **윤리** — 경험을 "발굴·강조"하되 **창작·과장하지 않습니다.** 모든 내용은 지원자 검증을 전제로 합니다.

> 📌 본 도구는 지원자의 실제 경험을 **정리·표현**하도록 돕습니다. 허위 경력 작성, 표절, 무비판적 AI 답변 제출은 권장하지 않으며, 산출물은 반드시 본인이 검토·소화한 뒤 활용하세요.
