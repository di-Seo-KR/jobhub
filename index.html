한국 취업시장에 최적화된 AI 취업 컨설팅 에이전트팀
⚙️ JobHub는 Claude Code 안에서 동작하는 에이전트팀입니다. 별도의 웹 서비스가 아니라, 이 저장소를 연 Claude Code 세션에서 자연어로 요청하면 8명의 컨설턴트가 협업해 자기소개서·면접·취업 전략을 지원합니다. (이 페이지는 소개용입니다.)

컨설팅 팀

intake-strategist진단·전략·종합 리포트
jd-analyst채용공고·직무 분석
experience-miner경험 STAR 구조화
resume-writer자기소개서 작성
resume-reviewer자소서 첨삭·평가
interview-designer예상 질문 설계
interview-coach답변·모의면접
market-researcher시장·기업 리서치

표준 워크플로우

  1. 인테이크·전략 수립 → intake-strategist
  2. 채용공고 분석 → jd-analyst (필요 시 market-researcher)
  3. 경험 은행 구축 → experience-miner
  4. 자소서 작성 → resume-writer
  5. 자소서 첨삭 (작성↔첨삭 반복) → resume-reviewer
  6. 예상 질문 설계 → interview-designer
  7. 답변·모의면접 → interview-coach
  8. 종합 리포트로 종결 → intake-strategist
